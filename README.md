# Cookie Clicker Web Clone 🍪

A feature-rich, pixel-for-pixel web clone of the legendary game **Cookie Clicker**, built using HTML5, CSS3, and modern modular ES6+ JavaScript.

## ✨ Features

- **Iconic 3-Column Layout**: Left Big Cookie & animated milk, Center news ticker & panels, Right store & upgrades.
- **Authentic Economy & Exact Formulas**: 
  - Progressive building costs: $\text{baseCost} \times 1.15^{\text{owned}}$
  - Bulk purchasing (1, 10, 100, Max) and selling refunds
- **129 Master Upgrades**: Cursor & Mouse tiers, fingers scaling, 7-tier building doublers for all 15 buildings, 25+ flavored biscuits, and the Kitten milk ladder.
- **150 Authentic Achievements**: Tracking production, CpS, click milestones, building thresholds, prestige, and shadow feats.
- **Secrets & Easter Eggs**:
  - **Cookie Dunker**: Drag the Big Cookie down into the milk to splash and unlock!
  - **Rubber Duck**: Squeak the rubber duck floating in the milk.
  - **Milk Splashing**: Realistic physics splash droplets on click.
  - **Bakery Names**: Secret responses for names like "Orteil" and "Ortiel".
  - **Grandmapocalypse & Wrinklers**: Fleshy leeches latch onto the cookie, digest CpS, and pop for 110% reward.
  - **Tiny Cookie & Mystery Slot**: Interactive secret triggers in the Stats menu.
- **Audio Engine**: 100% procedural Web Audio API synthesis (clicks, buy dings, chimes, fanfares, squeaks, squishes).
- **Persistence**: Auto-saving to LocalStorage, Base64 export/import, and offline cookie production.

## 🚀 How to Run Locally

Simply run any static HTTP server in the repository folder:

```bash
# Using Python:
python -m http.server 8888

# Open in browser:
http://localhost:8888
```
